# TRANSFERBRIDGE

An international football scouting and transfer-network website concept connecting players, scouts, agents and clubs across eight European leagues.

## Included in this repository

- Responsive landing page and navigation
- Player discovery interface with demo search and filters
- Eight league tabs and a club-directory starter dataset
- Role-specific entry points for players, scouts, agents and clubs
- Demo registration form with browser-local storage
- Vercel static-site configuration

## Run locally

This is a static website. No build command is required.

1. Open the repository folder.
2. Open `index.html` in a browser, or serve the folder with any static web server.
3. Deploy the repository to Vercel with the framework preset set to **Other**, leaving the build command and output directory empty.

## Important current limitations

This repository is the front-end preview, not yet the complete production platform. Registration currently saves demo data only in the visitor's browser. There is no connected authentication, cloud database, secure file/video storage, real messaging, admin moderation, or live transfer-submission workflow. Those features require a configured backend (for example Supabase), database policies, storage rules and server-side validation.

The club names are a starter directory dataset, not a verified official 2026/27 roster. Confirm the current league participants and official club recruitment channels before treating the directory as complete. The demo player profiles are fictional examples and are not real scouting recommendations.

TRANSFERBRIDGE does not guarantee trials, contracts or transfers. Users should independently verify club contacts, agent credentials and all recruitment requests.
